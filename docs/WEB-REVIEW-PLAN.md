# 个人复盘工作台：总体方案

建立日期：2026-10-15。状态：范围已确认，详细数据契约待 M0 审计。

## 总体目标

把每日指标汇总升级为可连续追踪、有证据、能验证判断的个人复盘工作台。
用户应能在首页一分钟内理解当天市场结构、重要变化及个人关注状态；
需要深入时可查看行情、事件、原始判断与后续结果。

全部模块纳入本轮范围，分里程碑交付不代表取消后续模块。
完成状态以 [实施记录](WEB-REVIEW-PROGRESS.md) 为准，计划不等于已实现。

## 完整范围与验收

### 已确认的使用约定（2026-10-15 讨论定稿）

- 收盘后更新，开盘前只回看昨晚报告；第一版不做盘前或盘中资讯更新。
- 手机优先，兼容iPad横竖屏。首页短列表，图表、来源和解释按需展开，不依赖横向大表格。
- 顺序：市场结构与变化、板块、我的关注、系统重点跟踪、简短兑现复盘。
- 系统最多展示10只，延续旧跟踪再补新机会；不凑数，完整候选可展开。
- 市场差时不新增推荐，解释“差在哪里”和“可能驱动”；旧跟踪仍展示状态和退出原因。
- 沪深主板进入可推荐范围；创业板仅研究观察，标记当前不可交易，不计入可操作推荐。
  该展示限制不修改原始信号或策略配置；仍遵守既有ST等过滤条件。
- 我的关注与系统池分开展示，重合标记但不重复铺开；允许录入股票代码，不录持仓、成本和资金。
- 我的关注保存在浏览器localStorage，手机与iPad分别添加，不自动同步；清除网站数据会丢失。
  用户已接受此取舍。笔记不是第一版必需功能，保留为后续可选项。
- 个股顺序：发生什么、原入选逻辑、支持与反对证据、后续观察条件。
  指标结合当日表现讲解；不把入选风险提示直接当作涨跌原因，不作个人持仓判断。
- 新闻有来源链接与发布时间，允许原因未知；原逻辑失效直接说明，不以“继续观察”掩盖。
- 保留观察区间、失效价及依据/日期；历史失效价格不能继续显示为当前有效计划。
- 首页成绩仅简短呈现，详情才展示收益、样本和数据质量；没有状态证据不编造延续/失效数量。
- 公网IP浏览器直接访问，不安装网络工具；第一版无登录、账户权限或社交。
  服务器只提供公开只读内容，不提供修改关注、重跑任务、发邮件等写接口。
  不公开内部日志、数据库配置或原始私有文件；公网内容不应包含私人资料。

| 模块 | 内容 | 可验证的完成条件 |
|---|---|---|
| 今日复盘 | 市场结构、重要变化、昨日兑现、明日观察 | 显示数据日期及质量；昨日比较使用相邻交易日；无变化不强凑结论 |
| 事件与涨跌解释 | 公告、新闻、政策及行情证据 | 来源、发布时间、采集时间可追溯；事实、推断、未知分开；盘后消息不得解释此前行情 |

| 策略成绩 | 策略分组、纠偏效果、误杀、覆盖与样本量 | 同期同池对照；缺少对照时明确不可比较；信号收益不冒充模拟或实际成交收益 |

| 邮件入口 | 简短变化摘要、网页链接、原有附件 | 与网页消费同版事实；预览不写发送成功；正文日期明确 |
| 部署与访问 | 无登录公开只读、轻量容器、健康检查、回滚 | 手机/iPad直接访问；不暴露写操作；现有服务正常运行 |

## 架构与业务边界

1. 行情、选股、评分、层级、仓位、评价继续由现有主链计算；网页不另建业务算法。
2. 新增展示查询接口，优先复用结构化产物及规范数据库视图；不把解析 Markdown 作为唯一事实入口。
3. 查询按日期、股票和分页限制规模；明确来源、版本、更新时间、质量及缺失状态。
4. 个人关注只存浏览器，业务数据只读；公开响应采用字段白名单，不能透传数据库行或全部JSON。
5. 事件采集和 LLM 解释在后台运行并缓存。页面请求不启动补数、选股或模型长任务。
6. 复用现有 LLM 事实包、适配器及治理入口，遵守 LLM-SIDECAR-CONTRACT.md。
   模型只解释，不改候选、评分、价格或仓位；无模型时正常展示已有事实。
7. 事件关联采用股票/板块身份与时间证据；不以关键词相同直接确认因果。
   历史解释须区分当时已知信息与事后补充信息。
8. 网页、邮件和导出共用展示数据契约；缺失值不转成零，未成熟评价不当失败。
9. 新依赖、API许可、费用和账号需求先核对。框架选型在检查现有代码后记录理由。

## 已知服务器约束

依据用户提供的截图：Ubuntu 24.04.2 / x86_64，2核，总内存约1.6 GiB，
截图时可用约686 MiB，无Swap，磁盘可用约21 GB，已有Docker及Compose。
80端口由法律工具容器占用；PostgreSQL已运行。日报运行峰值未测。

- 网页采用独立服务，计划使用8081；开发绑定本机，发布时按明确配置开放公网。
- 用户接受IP直接访问，无域名、不做登录；仅公开只读信息，个人关注不上传。
- 前端在本地或CI构建；服务器不部署本地大模型，不引入非必要常驻服务。
- 内存预算由实测决定，不依据空闲截图承诺夜间运行安全。
- 密钥、口令及私钥不进入仓库；示例只使用占位符。

## 变更控制

不顺带改变策略逻辑、收益定义或训练模型。发现此类需求先记录影响和独立验收项。
每阶段遵循原交接文档的行为等价门禁；没有可重放历史输入时记录限制，不声称通过。
明确的范围变化及付费依赖需记录用户决定。普通实现细节按总体目标推进。
