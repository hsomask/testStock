需求优先级以WEB-REVIEW-PLAN.md为准。

## 已核对的关键代码

| 来源 | 可复用内容 | 局限/接入要求 |
|---|---|---|
| analysis/daily_facts.py | 汇集market、sentiment、quality、trade_plan等现有结果 | 运行时对象，不等于已落盘的全量事实数据库 |
| analysis/daily_intelligence.py | 市场解读、T+1摘要、风险和LLM摘要输出 | intelligence_llm_view裁剪字段；缺完整候选；Markdown回退可能丢失结构，不作网页唯一来源 |
| analysis/daily_report.py | daily_summary_DATE.json | 有市场、情绪、主题、质量、watchlists；watchlists不能代替最终决策 |
| analysis/daily_decision.py | 唯一最终层级及交易模式定义 | 网页消费已保存结果，不重跑推导，不擅自给股票升级 |
| analysis/evaluation_report_reader.py | 规范评价读取和缺失状态 | 当前支持快照回退；网页必须标识正式/快照，不能混合统计 |
| analysis/correction_effectiveness.py | 纠偏结果、版本及质量分组 | 不同组均值不是同池因果对照；不能称为实际交易收益 |

## 已检查的真实本地产物

- daily_summary_20260626.json包含市场宽度、评分、主题、质量和策略候选。
- trade_plan_20260626.json包含market_restrictions、plans及价格条件；存在同股多策略。
- 该日allow_real_trade=false，max_position_pct=0，必须停止新增推荐。
- 历史产物可能没有decision字段，或存在多策略/跨层旧格式。不能静默套新算法改写历史；
  优先查询规范最终决策，缺失则标记legacy/待核验，仍可展示原始历史记录。
- 本地报告文件日期不连续；最近可用报告不一定是前一交易日。
  缺少相邻交易日时明确不可日比，不将跨度多日标成“较昨日”。

## 计划接口边界

| 查询 | 输入 | 响应要求 |
|---|---|---|
| 日期列表 | 有界分页 | 可用日期及产物完整度，不把文件修改时间当交易日 |
| 今日复盘 | YYYYMMDD | 日期、生成时间、市场/情绪/板块、交易限制、质量、来源版本 |
| 系统跟踪 | 日期 | 完整规范池及最多10只展示池分离；保留原层级和研究/可推荐标记 |
| 个股 | 六位代码、截至日期 | 当日事实、历史判断、价格条件有效性、成熟评价、证据引用 |
| K线 | 代码、截至日期、有界窗口 | OHLCV、复权口径、行情日期及缺口；不将当前复权价格与旧计划直接混比 |
| 事件 | 代码/板块、截至时间 | 来源URL、发布时间、首次采集时间、关联证据、是否事后补充 |
| 策略成绩 | 截至日期、有界窗口 | 明确样本粒度、覆盖、成熟度、版本；信号统计与交易结果分开 |
| 下载 | 日期、枚举类型 | 仅批准的公开产物；无任意路径/目录浏览，无日志或配置透传 |

所有响应含schema_version与状态；无数据为null或明确missing，不返回伪造默认值。
只读API不调用日报生成、邮件、数据库迁移、评价写入或模型。个人关注无服务器写接口。
公开字段显式选择，不直接序列化来源对象；第三方文本前端按文本渲染，链接只接受HTTP(S)。

## 持续跟踪待实施规则

- 连续性属于展示状态，不能改动selector、最终层级或原始排名。
- 旧跟踪和当天规范结果按股票身份关联，同时保留多策略明细。
- 未再次入选不自动等于失效；有明确反证才标记逻辑失效，否则写未再次入选/待核验。
- 历史价格需明确适用日期；不能将昨天价位当作今天新生成的价位。
- 弱市保留旧跟踪复盘但不新增推荐；创业板始终单独标记当前不可交易。
